    Editable Strings (UIString) API¶

    This document outlines how to use the Editable Strings (UIString) API to manage translations for the application.

    Overview¶

    The UIString feature allows for dynamic management of strings in the application's UI. Strings are stored as key-value pairs, with support for English and Arabic translations. The API provides endpoints for creating, retrieving, updating, and deleting these strings.

    Authentication¶

    All API endpoints require authentication. You must have the EDIT_UI_STRINGS permission to create, update, or delete UI strings.

    Endpoints¶

    Retrieve a UI String¶

    • GET /api/strings/{key}/

      Retrieves a single UI string by its key.

      Parameters:

      • key (string): The key of the UI string to retrieve.
      • lang (string, optional): The language to retrieve. Can be en or ar. Defaults to en.

      Example Request:

      bash curl -X GET -H "Authorization: Bearer <token>" "https://example.com/api/strings/welcome_message/?lang=ar"

      Example Response:

      json { "key": "welcome_message", "values": { "title": "مرحباً", "body": "مرحباً بك في تطبيقنا!" } }

    Create a UI String¶

    • POST /api/strings/

      Creates a new UI string.

      Example Request:

      bash curl -X POST -H "Authorization: Bearer <token>" -H "Content-Type: application/json" -d '{ "key": "new_feature_announcement", "values_en": { "title": "New Feature!", "description": "We have a new feature for you to try." }, "values_ar": { "title": "ميزة جديدة!", "description": "لدينا ميزة جديدة لتجربتها." } }' "https://example.com/api/strings/"

    Update a UI String¶

    • PUT or PATCH /api/strings/{key}/

      Updates an existing UI string.

      Example Request (PUT):

      bash curl -X PUT -H "Authorization: Bearer <token>" -H "Content-Type: application/json" -d '{ "key": "welcome_message", "values_en": { "title": "Welcome", "body": "Welcome to our app!" }, "values_ar": { "title": "أهلاً بك", "body": "أهلاً بك في تطبيقنا!" } }' "https://example.com/api/strings/welcome_message/"

      Example Request (PATCH):

      bash curl -X PATCH -H "Authorization: Bearer <token>" -H "Content-Type: application/json" -d '{ "values_en": { "title": "Welcome Back", "body": "Welcome back to our app!" } }' "https://example.com/api/strings/welcome_message/"

    Delete a UI String¶

    • DELETE /api/strings/{key}/

      Deletes a UI string.

      Example Request:

      bash curl -X DELETE -H "Authorization: Bearer <token>" "https://example.com/api/strings/welcome_message/"

    Validation Rules¶

    The following validation rules apply when creating or updating UI strings:

    • key: A unique string used to identify the UI string. This field is required when creating a new string and cannot be changed after creation.
    • values_en: A JSON object containing the English translations. This field is required, and its keys define the structure that values_ar must follow.
    • values_ar: A JSON object containing the Arabic translations. This field is optional and can be null or an empty JSON object ({}). If values_ar is provided and is not empty, it must contain the exact same set of keys as values_en.
