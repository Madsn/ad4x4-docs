    Global Settings¶

    This document lists all configurable system settings available in the AD4x4 API.

    Overview¶

    Global settings are managed via the Django Admin interface under ConfigurableSettings. These settings control system-wide behavior without requiring code changes.

    Accessing Settings¶

    API Endpoint¶

    GET /api/settings/

    Returns current configuration (requires authentication):

    {
  "defaultUserLevel": 10,
  "defaultUserGroup": 1,
  "enableAutoUpgradeOnLogbookEntry": false,
  "forceWaitlist": false,
  "tripEditDeleteCutoffMinutes": 0,
  "hereMapsEnabled": false,
  "enableGallerySystem": true,
  "autoCreateTripGallery": true,
  ...
}

    Settings Reference¶

    User Management¶

    Setting Field Name Type Default Description
    Default User Level default_user_level FK Required Level assigned to new users
    Default User Group default_user_group FK Optional Group assigned to new users

    Auto-Upgrade Settings¶

    Setting Field Name Type Default Description
    Enable Auto-Upgrade on Logbook Entry enable_auto_upgrade_on_logbook_entry Boolean false Auto-upgrade member after first logbook entry is created for them
    Auto-Upgrade Source Level auto_upgrade_source_level FK null Level to upgrade from
    Auto-Upgrade Target Level auto_upgrade_target_level FK null Level to upgrade to

    Email Settings¶

    Setting Field Name Type Default Description
    Email Sending Address email_sending_address Email noreply@ad4x4.com From address for emails
    Email Unsubscribe Address email_unsub_address Email unsub@ad4x4.com Unsubscribe footer address
    Email Support Address email_support_address Email support@ad4x4.com Support email address
    Email Sleep Period (ms) email_sleep_period_ms Integer 500 Delay between email batches

    Trip Settings¶

    Setting Field Name Type Default Description
    Force Waitlist force_waitlist Boolean false If true, trip leads cannot disable waitlist
    Trip Edit/Delete Cutoff (minutes) trip_edit_delete_cutoff_minutes Integer 0 Minutes before trip starts when editing/deleting is blocked

    HERE Maps Settings¶

    Setting Field Name Type Default Description
    HERE Maps Enabled here_maps_enabled Boolean false Enable reverse geocoding
    HERE Maps API Key here_maps_api_key String null API key for HERE Maps
    HERE Maps API Base URL here_maps_api_base_url String HERE API URL Base URL for geocoding API
    HERE Maps Selected Fields here_maps_selected_fields JSON [] Fields to return
    HERE Maps Max Fields here_maps_max_fields Integer 2 Max fields in area string
    HERE Maps Cache Duration (min) here_maps_cache_duration Integer 1440 Cache duration in minutes
    HERE Maps Request Timeout (s) here_maps_request_timeout Integer 10 Request timeout in seconds
    HERE Maps Available Fields here_maps_available_fields JSON See below Available field definitions

    HERE Maps Available Fields (default):

    [
  {"name": "title", "displayName": "Place Name"},
  {"name": "district", "displayName": "District"},
  {"name": "city", "displayName": "City"},
  {"name": "county", "displayName": "County"},
  {"name": "countryName", "displayName": "Country"},
  {"name": "postalCode", "displayName": "Postal Code"},
  {"name": "label", "displayName": "Full Address"},
  {"name": "categoryName", "displayName": "Category"}
]

    Gallery System Settings¶

    Setting Field Name Type Default Description
    Enable Gallery System enable_gallery_system Boolean true Master switch for gallery feature
    Auto Create Trip Gallery auto_create_trip_gallery Boolean true Auto-create gallery on trip approval
    Allow Manual Gallery Creation allow_manual_gallery_creation Boolean true Allow manual gallery creation
    Gallery API URL gallery_api_url String https://media.ad4x4.com External gallery API URL
    Gallery API Timeout (s) gallery_api_timeout Integer 30 API timeout in seconds

    Notification Settings¶

    Setting Field Name Type Default Description
    Notification Dry Run notification_dry_run Boolean true If true, notifications are logged but not sent

    Configuration via Admin¶

    Settings are managed in Django Admin at /admin/api/configurablesettings/.

    Only superusers can modify these settings.
