    Global Settings¶

    Minimum App Version Gate¶

    The global settings singleton now includes:

    • minimum_app_version (string, default empty)
    • minimum_app_version_message (text, default: Please update the AD4x4 app to continue.)

    If minimum_app_version is empty, version gate is disabled.

    Public Endpoint¶

    GET /api/app-version-gate

    Optional query parameter:

    • version (client app version)

    Response:

    {
  "minimumSupportedVersion": "1.4.0",
  "upgradeRequired": true,
  "upgradeMessage": "Please update the AD4x4 app to continue."
}

    Behavior:

    • Endpoint is unauthenticated.
    • If no minimum is configured, upgradeRequired is always false and message is empty.
    • If version is provided and lower than configured minimum, upgradeRequired is true.
    • Version comparison uses Python packaging.version.Version.
    • Pre-release versions compare lower than final releases, for example 1.4.0-beta.1 is lower than 1.4.0.
    • Flutter-style build strings are accepted. The build/local segment is considered when the public version is otherwise equal, so 1.7.7+90 is lower than 1.7.7+91.
    • Invalid client versions require upgrade when a valid minimum is configured.
    • Invalid configured minimum versions disable the gate and log an error.

    Auto Upgrade Settings¶

    The global settings singleton also controls the first-logbook-entry auto-upgrade flow:

    • enable_auto_upgrade_on_logbook_entry enables or disables the automatic upgrade path.
    • auto_upgrade_source_level is the level a member must currently hold for the auto-upgrade to trigger.
    • auto_upgrade_target_level is the level the member is moved to after their first qualifying logbook entry.

    When enabled, the backend automatically upgrades the member after the first logbook entry is created and adds them to the target level's auto_group if one is configured.

    Chat Link Preview Kill Switch¶

    • link_previews_enabled (boolean, default false)

    When disabled, GET /api/link-preview returns status: "disabled" and skips the fetch path entirely. Enable it in Django admin under the Global settings singleton when you are ready to serve preview cards.
