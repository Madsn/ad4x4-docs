    Permissions, Groups, and Levels¶

    This document provides a comprehensive overview of the permissions system used in the API. It details the different user groups, experience levels, and the specific actions each group is permitted to perform by default.

    Core Concepts¶

    The permissions system is built on three main concepts:

    • Groups: Users are assigned to one or more groups, which determine their general role and permissions.
    • Levels: Levels represent a user's experience or seniority within the club (e.g., Newbie, Intermediate, Marshal). Some permissions are restricted to certain levels.
    • Actions: These are specific permissions that grant the ability to perform a particular operation via the API (e.g., CREATE_TRIP, APPROVE_UPGRADE_REQ).

    Permissions are granted to groups, and can optionally be restricted to apply only to certain levels.

    Fetching User Permissions¶

    To get the permissions for a specific user, you can retrieve their profile from the /api/members/{id}/ endpoint. The user's permissions are included in the permissions array in the response.

    GET /api/members/{id}/

    Example Response Snippet:

    {
    "id": 1,
    "username": "testuser",
    ...
    "permissions": [
        "CREATE_TRIP",
        "VIEW_CONTACT_INFO"
    ],
    ...
}

    Groups and Levels¶

    The following table lists the default groups and their corresponding experience levels:

    Group Level Numeric Level Notes
    Newbies Newbie 10 Default for new users
    Intermediates Intermediate 100
    Advanced Advance 200
    Experts Expert 300 Disabled by default
    Explorers Explorer 400
    Marshals Marshal 600
    Board members Board member 800
    Non-level Groups
    Trip managers N/A N/A
    Meeting point managers N/A N/A
    Media managers N/A N/A
    Upgrade request managers N/A N/A
    Site admins N/A N/A Super-users with all permissions

    Default Permissions by Group¶

    Here is a breakdown of the default permissions assigned to each group.

    Newbies¶

    • Can search for members in the member directory.

    Explorers¶

    • Can create trips that require approval for the "Newbie" level.
    • Can create trips that do not require approval for "Intermediate" level and above.
    • Can create meeting points.
    • Can view contact information of other members.
    • Can create logbook entries and sign off on skills for trips they lead or support

    Marshals¶

    • Can create trips without requiring approval.
    • Can view, vote on, and comment on upgrade requests.

    Board Members¶

    • Can view, vote on, and comment on upgrade requests.
    • Can approve upgrade requests.
    • Can override the global waitlist setting for trips.

    Upgrade Request Managers¶

    • Can view, vote on, comment on, edit, and delete upgrade requests.
    • Can delete comments on upgrade requests.

    Trip Managers¶

    • Can create, edit, approve, and delete trips.
    • Can edit trip registrations and delete trip comments.
    • Can override the global waitlist setting for trips.
    • Have superuser permissions for creating logbook entries.

    Media Managers¶

    • Can edit trip media.

    Meeting Point Managers¶

    • Can create, edit, and delete meeting points.

    Site Admins¶

    • Have all permissions.

    Full List of Permissions (Actions)¶

    The following table lists all possible actions in the system.

    Action Description
    CREATE_TRIP Create Trip
    CREATE_TRIP_WITH_APPROVAL Create Trip With Approval
    CREATE_TRIP_REPORT Create Trip Report
    APPROVE_TRIP Approve Trip
    OVERRIDE_WAITLIST_SETTING Override Global Waitlist Setting
    BYPASS_LEVEL_REQ Bypass Level Requirements for Trip
    EDIT_TRIPS Edit Trips
    EDIT_TRIP_MEDIA Edit Trip Media
    EDIT_TRIP_REGISTRATIONS Edit Trip Registrations
    DELETE_TRIPS Delete Trips
    DELETE_TRIP_COMMENTS Delete Trip Comments
    CREATE_MEETING_POINTS Create Meeting Points
    EDIT_MEETING_POINTS Edit Meeting Points
    DELETE_MEETING_POINTS Delete Meeting Points
    CREATE_UPGRADE_REQ_FOR_SELF Create Upgrade Request For Self
    CREATE_UPGRADE_REQ_FOR_OTHERS Create Upgrade Request For Others
    EDIT_UPGRADE_REQ Edit Upgrade Request
    APPROVE_UPGRADE_REQ Approve Upgrade Request
    DELETE_UPGRADE_REQ Delete Upgrade Request
    VIEW_UPGRADE_REQ View Upgrade Request (ALL levels)
    VOTE_UPGRADE_REQ Vote Upgrade Request
    CREATE_COMMENT_UPGRADE_REQ Comment Upgrade Request
    DELETE_COMMENT_UPGRADE_REQ Delete Comment Upgrade Request
    EDIT_MEMBERSHIP_PAYMENTS Edit Membership Payments
    CREATE_LOGBOOK_ENTRIES Create Logbook Entries
    SIGN_LOGBOOK_SKILLS Sign Logbook Skills
    CREATE_LOGBOOK_ENTRIES_SUPERUSER Create Logbook Entries (superuser bypass)
    APPROVE_LOGBOOK_MIGRATION Approve Logbook Migration Requests
    ACCESS_MARSHAL_PANEL Access Marshal Panel
    VIEW_CONTACT_INFO View Contact Info
    SEARCH_MEMBERS Search Members
    CAN_BE_DEPUTY_LEAD Can Be Deputy Lead
    EDIT_UI_STRINGS Edit UI Strings
    EDIT_GLOBAL_SETTINGS Edit Global Settings
