    Authentication and Profiles¶

    This document outlines the API endpoints for user authentication, registration, and profile management.

    For a high-level overview of the authentication process, please refer to the API Concepts document.

    Registration and Password Management¶

    The API provides endpoints for user registration and password management, powered by the rest_registration library.

    Registration¶

    POST /api/auth/register/

    The request body should include the user's details. Refer to the MemberRegistrationSerializer for the full list of required and optional fields.

    Change Password¶

    Authenticated users can change their password by making a POST request to /api/auth/change-password/.

    POST /api/auth/change-password/

    Request Body:

    {
    "old_password": "current_password",
    "password": "new_password",
    "password2": "new_password_confirmation"
}

    Note: password and password2 must match.

    Other Endpoints¶

    The rest_registration library also provides endpoints for: * Resetting a forgotten password * Verifying registration via email

    Please refer to the library's documentation for details on these flows.

    Profile Management¶

    Retrieving a Profile¶

    To retrieve a user's profile, make a GET request to /api/members/{id}/.

    GET /api/members/{id}/

    Success Response: The response will be a JSON object containing the user's profile information. The fields returned are defined by the ProfileSerializer.

    Note: While the serializer and database use snake_case for field names (e.g., first_name), the API will return camelCase in the response body (e.g., firstName).

    {
    "id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "firstName": "Test",
    "lastName": "User",
    "phone": "1234567890",
    "carBrand": "Toyota",
    "carModel": "Land Cruiser",
    "carYear": 2022,
    "carColor": "White",
    "carImage": null,
    "dob": "2000-01-01",
    "iceName": "Jane Doe",
    "icePhone": "0987654321",
    "level": {
        "id": 1,
        "name": "Newbie"
    },
    "tripCount": 5,
    "avatar": null,
    "permissions": [...],
    "paidMember": true,
    "dateJoined": "2023-01-01T12:00:00Z",
    "city": "Dubai",
    "gender": "M",
    "nationality": "AE",
    "title": ""
}

    Updating a Profile¶

    To update a user's profile, make a PATCH request to /api/members/{id}/. Users can only update their own profiles unless they are an administrator.

    PATCH /api/members/{id}/

    Request Body: The request body should contain the fields to be updated. For a list of editable fields, refer to the EditMemberSerializer. Note that some fields like username, email, and level are read-only.

    Success Response: A successful update will return a 200 OK status code and the updated profile data.
