    Members¶

    This document outlines the API endpoints for member management, including searching for members, retrieving member profiles, and managing member information.

    For authentication and registration details, please refer to the Authentication and Profiles document.

    Member List¶

    You can retrieve a list of members using the standard ViewSet endpoint.

    GET /api/members/

    Authentication: Optional (public endpoint, but contact info requires authentication and permissions)

    Query Parameters:

    Parameter Type Description
    trip_count integer Filter by exact trip count
    trip_count__range string Filter by trip count range (e.g., 5,20)
    phone string Filter by exact phone number
    phone__icontains string Filter by partial phone number
    level__numeric_level integer Filter by exact numeric level
    level__numeric_level__range string Filter by numeric level range
    level__name string Filter by exact level name
    level__name__icontains string Filter by partial level name
    email string Filter by exact email address
    email__icontains string Filter by partial email (contains)
    first_name string Filter by exact first name
    first_name__icontains string Filter by partial first name
    last_name string Filter by exact last name
    last_name__icontains string Filter by partial last name
    level__id integer Filter by level ID
    nationality string Filter by exact nationality code
    city string Filter by exact city
    paid_member boolean Filter by payment status (true or false)
    last_visited__isnull boolean Filter by visit status (true = never visited, false = visited at least once)
    last_visited_after datetime Filter members who last visited after this date/time (ISO 8601)
    last_visited_before datetime Filter members who last visited before this date/time (ISO 8601)
    date_joined_after date Filter members who joined after this date (e.g., 2026-03-01)
    date_joined_before date Filter members who joined before this date (e.g., 2026-04-01)
    search string Text search across username, first name, last name, and email (case-insensitive partial match). Optional — omitting returns all members.
    ordering string Sort results. Accepted values: username, first_name, last_name, trip_count, level__numeric_level, date_joined, id, last_visited. Prefix with - for descending (e.g., -trip_count). Multi-field: -trip_count,username. Default: id.
    page integer Page number (default: 1)
    page_size integer Number of results per page (default: 20, max: 500)

    Note: Vehicle-related filters (car_brand, car_year) are NOT supported. Vehicle data is managed separately via the Vehicles endpoints.

    Success Response:

    {
  "count": 100,
  "next": "http://api.example.com/api/members/?page=2",
  "previous": null,
  "results": [
    {
      "id": 1,
      "username": "testuser",
      "firstName": "Test",
      "lastName": "User",
      "level": "Newbie",
      "tripCount": 5,
      "paidMember": true,
      "lastVisited": "2026-03-30T14:22:00Z"
    }
  ]
}

    Note: In the list response, level is returned as a string (level name). In the detail response (/api/members/{id}/), level is a full object. Contact information (email, phone) is only visible to users with the VIEW_CONTACT_INFO permission or when viewing their own profile.

    Search Members¶

    Search for members by username, first name, or last name. This is useful for finding members when adding trip participants, looking up member profiles, or searching for trip leads.

    GET /api/members/search

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters:

    Parameter Type Required Description
    query string Yes Search term - must be at least 3 characters. Matches against username, first name, and last name (case-insensitive partial match)
    level integer No Level ID for filtering to include only members at a specific level
    min_level integer No Minimum numeric level for filtering (inclusive)
    max_level integer No Maximum numeric level for filtering (inclusive)
    page integer No Page number (default: 1)
    page_size integer No Number of results per page (default: 20, max: 500)

    Level Filtering Examples:

    # Search for Newbies (level ID 10)
GET /api/members/search?query=john&level=10

# Search for members up to Intermediate (numeric level 100) inclusive
GET /api/members/search?query=john&max_level=100

# Search for members Intermediate (numeric level 100) and higher inclusive
GET /api/members/search?query=john&min_level=100

    Request Example:

    # Basic search
curl -X GET "http://localhost:8000/api/members/search?query=john&page=1&page_size=20" \
  -H "Authorization: Bearer <your-token>"

    Success Response (200 OK):

    {
  "count": 42,
  "next": "http://api.example.com/api/members/search?query=john&page=2",
  "previous": null,
  "results": [
    {
      "id": 1,
      "username": "johndoe",
      "firstName": "John",
      "lastName": "Doe",
      "level": "Marshal",
      "tripCount": 25,
      "paidMember": true,
      "lastVisited": "2026-03-30T14:22:00Z"
    }
  ]
}

    Error Response (400 Bad Request - Missing query):

    {
  "success": false,
  "message": "query_parameter_required"
}

    Error Response (400 Bad Request - Query too short):

    {
  "success": false,
  "message": "query_too_short"
}

    Error Response (401 Unauthorized):

    {
  "detail": "Authentication credentials were not provided."
}

    Error Response (403 Forbidden):

    {
  "detail": "You do not have permission to perform this action."
}

    Notes: - The search is case-insensitive and performs partial matching (contains) - Query must be at least 3 characters long - Results are ordered by trip_count (descending), then by id (ascending) - Results are paginated using standard pagination - Matches across username, first_name, and last_name fields using OR logic - Results can be filtered by level using level, min_level, or max_level parameters - Contact information (email, phone) is only visible to users with the VIEW_CONTACT_INFO permission or when viewing their own profile - Permission Required: Users must have the SEARCH_MEMBERS permission to use this endpoint. By default, this is granted to Newbie level and above. ANIT members cannot use this endpoint.

    Member Profile Details¶

    Retrieve detailed information about a specific member.

    GET /api/members/{id}/

    Success Response:

    {
  "id": 1,
  "username": "testuser",
  "email": "test@example.com",
  "firstName": "Test",
  "lastName": "User",
  "phone": "1234567890",
  "dob": "2000-01-01",
  "iceName": "Jane Doe",
  "icePhone": "0987654321",
  "level": {
    "id": 1,
    "name": "Newbie",
    "numericLevel": 10,
    "minTripsForUpgrade": 5
  },
  "tripCount": 5,
  "avatar": null,
  "permissions": [
    {
      "id": 1,
      "action": "search_members",
      "levels": []
    }
  ],
  "paidMember": true,
  "dateJoined": "2026-01-01T12:00:00",
  "city": "Dubai",
  "gender": "M",
  "nationality": "AE",
  "title": "",
  "lastVisited": "2026-03-30T14:22:00Z"
}

    Note: The profile detail does NOT include vehicle/car fields. Vehicles are managed separately via the Vehicles endpoints. The level field is a full object in the detail view, whereas it is a string in the list view.

    Update Member Profile¶

    Update a member's profile. Users can only update their own profiles unless they are an administrator.

    PATCH /api/members/{id}/

    Request Body: The request body should contain the fields to be updated. Note that some fields like username, email, level, tripCount, and paidMember are read-only.

    Success Response: A successful update will return a 200 OK status code and the updated profile data.

    Member Trip Counts¶

    Retrieve a detailed breakdown of a member's trip counts by level.

    GET /api/members/{id}/tripcounts

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - since - Optional ISO date (YYYY-MM-DD). Includes trips with start_time on or after this date. - until - Optional ISO date (YYYY-MM-DD). Includes trips with start_time before this date.

    Success Response: Returns a per-level summary of a member's trips. count preserves the legacy trip-total semantics, including lead and deputy-lead trips. registeredCount and attendanceRate are based only on completed trip registrations, and levels with registrations but no completed check-ins can still appear with count: 0.

    {
  "member": {
    "id": 1,
    "username": "johndoe"
  },
  "tripStats": [
    {
      "levelName": "Beginner",
      "levelNumeric": 15,
      "count": 12,
      "registeredCount": 10,
      "attendanceRate": 0.8
    }
  ]
}

    Lead Search¶

    Search for members who have permission to lead trips.

    GET /api/members/leadsearch

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - search - Search term (searches in username, first name, last name) - level - Level ID for filtering to include only members that have permission to lead for a given level

    Success Response:

    [
  {
    "id": 1,
    "username": "johndoe",
    "firstName": "John",
    "lastName": "Doe",
    "level": "Marshal",
    "tripCount": 25,
    "paidMember": true,
    "lastVisited": "2026-03-30T14:22:00Z"
  }
]

    Note: This endpoint returns up to 30 results without pagination. Returns a plain array, not a paginated object.

    Marshals Directory¶

    Return the public Marshals and Board directory for any authenticated member.

    GET /api/members/marshals

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - includeMarshals - Include marshal-level members in the directory (default: true) - includeBoard - Include board-level members in the directory (default: true)

    Success Response:

    [
  {
    "id": 1,
    "username": "marshal_john",
    "firstName": "John",
    "lastName": "Doe",
    "level": "Marshal",
    "numericLevel": 600,
    "tripCount": 25,
    "avatar": "https://ap.ad4x4.com/uploads/avatars/2026/05/marshal_john.png",
    "paidMember": true,
    "lastVisited": "2026-03-30T14:22:00Z"
  }
]

    Note: This endpoint returns a plain array, not a paginated object. It excludes contact fields and inactive members.

    Note: If both includeMarshals and includeBoard are false, the API returns 400 Bad Request with at_least_one_level_must_be_included.

    Marshal Leaderboard¶

    Return the top marshals or board members by trips led for a given period.

    GET /api/members/marshals/leaderboard

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - since - Optional ISO date (YYYY-MM-DD). Includes trips with start_time on or after this date. - until - Optional ISO date (YYYY-MM-DD). Includes trips with start_time before this date. - numericLevel - Member level to include. Defaults to 600 (Marshals). Pass 800 for Board members. - limit - Maximum number of rows to return. Defaults to 10.

    Success Response:

    [
  {
    "id": 1,
    "username": "marshal_john",
    "firstName": "John",
    "lastName": "Doe",
    "avatar": "https://ap.ad4x4.com/uploads/avatars/2026/05/marshal_john.png",
    "tripsLed": 25,
    "tripsLedByLevel": [
      {
        "levelName": "Newbie",
        "levelNumeric": 10,
        "levelActive": true,
        "tripsLed": 12
      },
      {
        "levelName": "Retired Sand",
        "levelNumeric": 150,
        "levelActive": false,
        "tripsLed": 3
      },
      {
        "levelName": "Advanced",
        "levelNumeric": 200,
        "levelActive": true,
        "tripsLed": 7
      }
    ]
  }
]

    Note: The response is a plain array, not paginated. tripsLedByLevel is derived from the actual led-trip history in the selected window and includes inactive trip levels when historical trips used them.

    Active Trip Leads¶

    Retrieve unique leads of active trips.

    GET /api/members/activetripleads

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - level - Level ID for filtering to include only leads for trips for a specific level - min_numeric_level - Minimum trip numeric level for filtering - max_numeric_level - Maximum trip numeric level for filtering

    Success Response:

    [
  {
    "id": 1,
    "username": "johndoe",
    "firstName": "John",
    "lastName": "Doe",
    "level": "Marshal",
    "tripCount": 25,
    "paidMember": true,
    "lastVisited": "2026-03-30T14:22:00Z"
  }
]

    Note: This endpoint returns up to 50 results without pagination. Returns a plain array, not a paginated object.

    Member Trip History¶

    Retrieve a member's trip history.

    GET /api/members/{id}/triphistory

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Query Parameters: - checked_in - Include only trips where member is checked in (default: false) - start_time - Filter by start time

    Permissions: - Users can always view their own trip history. - To view another member's trip history, users need the VIEW_MEMBER_TRIP_HISTORY permission. - Superusers can view any member's trip history.

    Response Fields:

    Field Type Description
    id integer Trip ID
    title string Trip title
    description string Trip description
    startTime datetime Trip start time
    endTime datetime Trip end time
    lead object Trip lead {id, username}
    level object Level {id, name, numericLevel, minTripsForUpgrade, active, displayName}
    checkedIn boolean Whether the member is checked in for this trip
    image string/null Trip cover image URL
    meetingPoint object/null Meeting point {id, name, area, lat, lon, link}
    registeredCount integer Number of registered members
    capacity integer Trip capacity
    allowWaitlist boolean Whether the trip allows waitlisting
    approvalStatus string Approval status (A, P, C)
    isRegistered boolean Whether the target member is registered
    isWaitlisted boolean Whether the target member is on the waitlist

    Note: This endpoint does NOT use a trailing slash.

    Member Feedback¶

    Retrieve a member's feedback submissions.

    GET /api/members/{id}/feedback

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Permissions: - Users can always view their own feedback. - Superusers can view any member's feedback. - Non-superusers cannot view another member's feedback, regardless of other permissions.

    Member Payments¶

    Manually update the paidMember field for a member.

    POST /api/members/{id}/payments

    Note: This endpoint does NOT use a trailing slash.

    Authentication: Required (Bearer token)

    Permission: Requires EDIT_MEMBERSHIP_PAYMENTS permission.

    Request Body:

    {
  "paymentReceived": "true"
}

    Success Response:

    {
  "success": true,
  "message": "payment_status_updated"
}
