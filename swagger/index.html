    Swagger UI¶

    Our API documentation is powered by Swagger, which provides an interactive way to explore and test the API.

    Access URLs¶

    Environment URL
    Production https://ap.ad4x4.com/docs/swagger-ui/
    Local Development http://localhost:8000/docs/swagger-ui/

    Authorizing with a Bearer Token¶

    To test the protected endpoints in the Swagger UI, you'll need to obtain a bearer token and authorize your requests. Here's how to do it:

    1. Log in to the API: Send a POST request to the /api/auth/login/ endpoint with your username and password. The response will contain an access token.

    2. Authorize in Swagger:

      • Click the "Authorize" button at the top-right of the Swagger page.
      • In the dialog that appears, enter the word Bearer followed by a space and then the access token you received in the previous step. For example: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
      • Click "Authorize" to save the token.

    Once you've authorized, you can make requests to any of the protected endpoints in the Swagger UI.
