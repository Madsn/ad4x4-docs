    Rate Limiting¶

    To ensure the stability and reliability of the AD4x4 API, we have implemented rate limiting at two levels: Nginx and Django REST Framework (DRF).

    Configuration¶

    Nginx Rate Limiting¶

    The rate limiting is configured in the Nginx default.conf.template file. The current limit is set to 100 requests per minute per IP address for most API endpoints, with stricter limits on registration endpoints.

    Django DRF Rate Limiting¶

    The API also implements Django REST Framework throttling:

    User Type Rate
    Anonymous users 100 requests/minute
    Authenticated users 200 requests/minute

    HTTP 429 Response¶

    If you exceed the rate limit, the API will respond with an HTTP 429 Too Many Requests status code. When you receive this response, you should:

    • Stop sending requests: Do not send any more requests until the rate limit window has reset.
    • Inform the user: Display a message to the user indicating that they have exceeded the rate limit and should try again later.
    • Implement backoff: Consider implementing an exponential backoff strategy to gradually reduce the rate of your requests.
