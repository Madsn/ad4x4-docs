    Trip Reports¶

    Trip reports allow trip leads or deputies to document completed trips with photos, track files, and narrative descriptions.

    Model Overview¶

    Field Type Description
    trip ForeignKey The trip this report is for
    title CharField(40) Short title for the report
    report_text TextField Full narrative description
    track_file FileField GPX or similar track file (optional)
    track_image ImageField Featured image for the track (optional)
    member ForeignKey Member who created the report
    created DateTimeField Auto-generated creation timestamp
    images Reverse FK Related TripReportImage objects

    Endpoints¶

    List Trip Reports¶

    • GET /api/tripreports/
    • Authentication: Required
    • Response: Paginated list of trip reports

    Query Parameters: | Parameter | Type | Description | |-----------|------|-------------| | trip | Integer | Filter by trip ID | | member | Integer | Filter by author ID | | ordering | String | Order by field (default: -id) |

    Response Format:

    {
    "count": 5,
    "next": null,
    "previous": null,
    "results": [
        {
            "id": 1,
            "trip": 123,
            "title": "Wadi Bih Run",
            "trackFile": "/media/trip_reports/...",
            "trackImage": "/media/trip_reports/..."
        }
    ]
}

    Create Trip Report¶

    • POST /api/tripreports/
    • Authentication: Required
    • Permissions: Trip Lead or Deputy only
    • Content-Type: multipart/form-data

    Request Body: | Field | Type | Required | Description | |-------|------|----------|-------------| | trip | Integer | Yes | Trip ID | | title | String | Yes | Report title (max 40 chars) | | reportText | String | Yes | Full report content | | trackFile | File | No | GPX track file | | trackImage | File | No | Featured track image | | imageFiles | Array[File] | No | Additional trip photos |

    Example Request:

    curl -X POST /api/tripreports/ \
  -H "Authorization: Bearer <token>" \
  -F "trip=123" \
  -F "title=Wadi Bih Run" \
  -F "reportText=Great trip everyone!" \
  -F "trackFile=@track.gpx" \
  -F "imageFiles=@photo1.jpg" \
  -F "imageFiles=@photo2.jpg"

    Response:

    {
    "success": true,
    "message": "trip_report_created"
}

    Retrieve Trip Report¶

    • GET /api/tripreports/{id}/
    • Authentication: Required

    Response:

    {
    "success": true,
    "message": {
        "id": 1,
        "trip": 123,
        "title": "Wadi Bih Run",
        "reportText": "Great trip everyone!",
        "trackFile": "/media/trip_reports/...",
        "trackImage": "/media/trip_reports/...",
        "images": [
            {"id": 1, "image": "/media/trip_reports/..."}
        ],
        "member": {
            "id": 45,
            "username": "johndoe",
            "displayName": "John Doe"
        },
        "created": "2024-01-15T10:30:00Z"
    }
}

    Update Trip Report¶

    • PUT/PATCH /api/tripreports/{id}/
    • Authentication: Required
    • Permissions: Creator only

    Only the report creator can update the report. Replaces all images when updating.

    Delete Trip Report¶

    • DELETE /api/tripreports/{id}/
    • Authentication: Required
    • Permissions: Creator only

    Permanently removes the report and all associated images.

    File Upload Paths¶

    File Type Upload Path
    Track files trip_reports/{YYYY}/{MM}/files/{filename}
    Track images trip_reports/{YYYY}/{MM}/images/{filename}
    Gallery images trip_reports/{YYYY}/{MM}/images/{filename}
