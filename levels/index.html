    Levels¶

    This document outlines the API endpoints for viewing member levels (experience tiers).

    Overview¶

    Levels represent experience/seniority tiers in the club (e.g., Newbie, Intermediate, Explorer, Marshal). They determine which trips a member can join, which permissions they have, and when they are eligible for an upgrade.

    Levels are managed by administrators via Django Admin. The API provides read-only access.

    Endpoints¶

    List Levels¶

    • GET /api/levels/
      • Retrieves a list of all levels.
      • Authentication: Optional (public endpoint).
    • GET /api/levels/?include_member_counts=true
      • Retrieves the same list with memberCount on each item.
      • Authentication: Required.

    Query Parameters:

    Parameter Type Description
    name string Filter by exact name
    name__icontains string Filter by name (case-insensitive partial match)
    numeric_level integer Filter by exact numeric level
    numeric_level__range string Filter by numeric level range (e.g., 10,400)
    active boolean Filter by active status (true or false)
    include_member_counts boolean When true, include memberCount for active members only

    Example Request:

    curl -X GET "http://localhost:8000/api/levels/"

    curl -H "Authorization: Bearer <token>" \
  -X GET "http://localhost:8000/api/levels/?include_member_counts=true"

    Example Response:

    {
    "count": 5,
    "next": null,
    "previous": null,
    "results": [
        {
            "id": 1,
            "name": "Newbie",
            "numericLevel": 10,
            "displayName": "Newbie",
            "active": true,
            "minTripsForUpgrade": 5
        },
        {
            "id": 2,
            "name": "Intermediate",
            "numericLevel": 100,
            "displayName": "Intermediate",
            "active": true,
            "minTripsForUpgrade": 10
        }
    ]
}

    Note: The response is paginated through DRF's default page-number pagination. Results are ordered by numeric_level ascending. Note: When include_member_counts=true, each item in results also includes memberCount.

    Retrieve a Level¶

    • GET /api/levels/{id}/
      • Retrieves the details of a single level.
      • Authentication: Optional (public endpoint).

    Example Response:

    {
    "id": 1,
    "name": "Newbie",
    "numericLevel": 10,
    "displayName": "Newbie",
    "active": true,
    "minTripsForUpgrade": 5
}

    Response Fields¶

    Field Type Description
    id integer Unique level ID (read-only)
    name string Level name (e.g., "Newbie", "Marshal")
    numericLevel integer Numeric value representing seniority (1-999). Higher = more senior.
    displayName string Display name used in the client for trips
    active boolean Whether the level is currently active. Inactive levels are hidden from selection lists.
    minTripsForUpgrade integer Minimum number of completed trips required at this level before a member can apply for an upgrade (read-only)
    memberCount integer Number of active members at this level. Present only when include_member_counts=true.

    Note: The auto_group field (Django Group assigned on upgrade) is excluded from the API response. It is configured via Django Admin only. Note: memberCount excludes soft-deleted members and can be requested with include_member_counts=true.

    Default Levels¶

    Name Numeric Level Notes
    Newbie 10 Entry level for new members
    Intermediate 100 After first upgrade
    Advanced 200 Disabled by default (active: false)
    Explorer 400 Experienced members
    Marshal 600 Trip leaders
    Board 800 Board members (admin group, not a trip level)
