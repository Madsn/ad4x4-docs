    Choices (Enum Endpoints)¶

    This document outlines the API endpoints that return enumeration (choice) values used throughout the application.

    Overview¶

    Choice endpoints provide the valid values for dropdown menus, filters, and form fields. Each endpoint returns a paginated list of {value, label} objects.

    All choice endpoints:

    • Do NOT use trailing slashes
    • Authentication: Not required (public endpoints)
    • Pagination: page_size=500 (effectively returns all values in one page)

    Response Format¶

    All choice endpoints return the same paginated structure:

    {
    "count": 5,
    "next": null,
    "previous": null,
    "results": [
        {"value": "CODE", "label": "Display Name"},
        {"value": "CODE2", "label": "Another Name"}
    ]
}

    Endpoints¶

    Countries¶

    • GET /api/choices/countries
      • Returns the list of country codes and names.

    Gender¶

    • GET /api/choices/gender
      • Returns gender options.
    Value Label
    M Male
    F Female
    O Other

    Trip Approval Status¶

    • GET /api/choices/approvalstatus
      • Returns trip approval status values.
    Value Label
    P Pending Approval
    A Approved
    R Rejected
    C Canceled

    Upgrade Request Status¶

    • GET /api/choices/upgraderequeststatus
      • Returns upgrade request status values.
    Value Label
    N New
    I In Progress
    A Approved
    D Declined

    Upgrade Request Vote¶

    • GET /api/choices/upgraderequestvote
      • Returns vote choice values for upgrade requests.
    Value Label
    Y Yes
    N No
    D Defer

    Car Brands¶

    • GET /api/choices/carbrand
      • Returns the list of valid car brand codes (73 brands + OTHER).

    Example values:

    Value Label
    AB Abarth
    AU Audi
    BM BMW
    FO Ford
    JE Jeep
    LR Land Rover
    ME Mercedes-Benz
    NI Nissan
    TO Toyota
    OT Other

    See Vehicles for the full brand code table.

    Time of Day¶

    • GET /api/choices/timeofday
      • Returns time-of-day options for trip requests.
    Value Label
    MOR Morning
    MID Mid-day
    AFT Afternoon
    EVE Evening
    ANY Any

    Permission Matrix Actions¶

    • GET /api/choices/permissionmatrixaction
      • Returns all available permission action identifiers.

    Example values: create_trip, approve_trip, edit_trips, delete_trips, vote_upgrade_req, create_logbook_entries, search_members, view_contact_info, etc.

    Note: All action values are lowercase strings matching the DB value (e.g., "create_trip", not "CREATE_TRIP"). See Permissions for the full list with their exact DB values.

    See Permissions for the full list of actions and their descriptions.

    Trip Request Areas¶

    • GET /api/choices/triprequestarea
      • Returns area options for trip requests.
    Value Label
    DXB Dubai
    NOR Northern Emirates
    AUH Abu Dhabi
    AAN Al Ain
    LIW Liwa

    Emirates¶

    • GET /api/choices/emirates
      • Returns the list of UAE emirates.
    Value Label
    AU Abu Dhabi
    DU Dubai
    SH Sharjah
    RK Ras al-Khaimah
    UQ Umm al-Quwain
    FU Fujairah
    AJ Ajman

    Use Cases¶

    • Registration forms: Populate gender, nationality (countries), and city (emirates) dropdowns
    • Trip creation: Populate approval status, level, and meeting point area fields
    • Vehicle forms: Populate car brand dropdown
    • Trip requests: Populate time-of-day and area selectors
    • Upgrade requests: Display vote options and status labels
    • Admin dashboards: Populate permission action selectors
