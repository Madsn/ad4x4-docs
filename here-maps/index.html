    HERE Maps Integration¶

    This document outlines the configuration and API endpoints for the HERE Maps reverse geocoding feature.

    Admin Configuration¶

    The HERE Maps integration is configured through the Global Settings in the Django Admin interface. The following fields are available:

    • Here Maps Enabled: Master switch to enable or disable the entire HERE Maps feature.
    • Here Maps Api Key: Your HERE Maps API key.
    • Here Maps Api Base Url: The base URL for the HERE Maps reverse geocoding API.
    • Here Maps Selected Fields: A JSON list of fields to be returned by the reverse geocoding endpoint (e.g., ["city", "district"]).
    • Here Maps Max Fields: The maximum number of fields to display in the formatted area string.
    • Here Maps Available Fields: A JSON object defining the available fields and their display names (e.g., {"city": "City", "district": "District"}).
    • Here Maps Cache Duration: The duration, in days, for which geocoding results are cached in the database.
    • Here Maps Request Timeout: The timeout, in seconds, for requests to the HERE Maps API.

    API Endpoints¶

    Get HERE Maps Configuration¶

    This public endpoint provides the necessary configuration for the frontend to interact with the HERE Maps feature.

    • Endpoint: GET /api/settings/here-maps-config/
    • Authentication: None
    • Response: json { "enabled": true, "selectedFields": ["district", "city"], "maxFields": 2, "availableFields": [ {"name": "title", "displayName": "Place Name"}, {"name": "district", "displayName": "District"}, {"name": "city", "displayName": "City"} ] }

    Reverse Geocode Coordinates¶

    This endpoint takes a latitude and longitude and returns a formatted area string based on the configured selectedFields and maxFields.

    • Endpoint: POST /api/geocoding/reverse/
    • Authentication: Required
    • Request Body: json { "latitude": 24.4539, "longitude": 54.3773 }
    • Responses:
      • 200 OK: json { "success": true, "area": "Al Ain, Abu Dhabi", "fields": { "district": "Al Ain", "city": "Abu Dhabi" }, "cached": false }
      • 400 Bad Request: If latitude or longitude are missing or invalid.
      • 401 Unauthorized: If the user is not authenticated.
      • 500 Internal Server Error: If there is an error communicating with the HERE Maps API.
