    Sponsorships¶

    The sponsorship system manages club sponsors and their associated branding assets. Sponsors are displayed on the frontend based on priority and active date range.

    Model Overview¶

    Field Type Description
    id Integer Unique identifier
    title CharField(100) Sponsor name
    description TextField Sponsor details or slogan
    priority Integer Display order (lower = higher priority)
    image ImageField Sponsor logo
    start_date DateField When sponsorship becomes active (default: today)
    end_date DateField When sponsorship expires (optional)

    Endpoints¶

    List Active Sponsors¶

    • GET /api/sponsors/
    • Authentication: Not required (public endpoint)
    • Pagination: Disabled

    Note: The endpoint is /api/sponsors/ (not /api/sponsorships/).

    Filtering: Only sponsors where end_date is null OR end_date > today are returned.

    Ordering: Results are sorted by priority (ascending).

    Response:

    Returns a plain array (no pagination wrapper, no success/message envelope):

    [
    {
        "id": 1,
        "title": "OffRoad Pro",
        "description": "Premium off-road equipment",
        "priority": 10,
        "image": "/media/avatars/2026/01/sponsor_abc123.jpg"
    },
    {
        "id": 2,
        "title": "Desert Tires",
        "description": "All-terrain tires for extreme conditions",
        "priority": 20,
        "image": "/media/avatars/2026/01/sponsor_def456.jpg"
    }
]

    Retrieve Sponsor¶

    • GET /api/sponsors/{id}/
    • Authentication: Not required (public endpoint)

    Response:

    {
    "id": 1,
    "title": "OffRoad Pro",
    "description": "Premium off-road equipment",
    "priority": 10,
    "image": "/media/avatars/2026/01/sponsor_abc123.jpg"
}

    Display Logic¶

    Active Sponsor Check¶

    A sponsor is considered active when:

    end_date is None OR end_date > today

    Priority Ordering¶

    Lower priority values appear first in the list. Example: - Priority 10: Appears before priority 20 - Priority 100: Appears last

    File Upload Path¶

    Logos are stored at: avatars/{YYYY}/{MM}/{filename}

    Use Cases¶

    1. Homepage Banner: Display top 3-5 sponsors by priority
    2. Sponsor Gallery: Full list of all active sponsors
    3. Footer: Persistent sponsor logos
    4. Event Pages: Event-specific sponsors with dedicated priority

    Admin Configuration¶

    Sponsors are managed in Django Admin under the Sponsors section. Administrators can:

    • Add new sponsors with logo uploads
    • Set priority values for ordering
    • Configure start and end dates for campaigns
    • Edit sponsor descriptions and titles

    Permissions¶

    Action Permission Required
    List/Retrieve AllowAny (public)
    Create/Update/Delete Django admin only
