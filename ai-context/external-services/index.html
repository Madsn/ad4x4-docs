    External Services¶

    AI-context reference. Wire-up for each integration plus what holds the credentials.

    Service Purpose Config location
    Firebase FCM Push notifications FCM_SERVICE_KEY_PATH env var; fcm_django in INSTALLED_APPS
    Telegram Bot Admin-facing notifications, host-monitor bot, GitHub PR alerts TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID env vars; topic-specific thread IDs documented in deployment.md
    HERE Maps Reverse geocoding ConfigurableSettings.here_maps_* fields. apiKey is a request parameter — keep API errors generic and avoid logging full request URLs so the key is not exposed in responses or logs.
    Gallery API Trip photo albums GALLERY_API_BASE_URL + GALLERY_API_TOKEN env vars; ConfigurableSettings.gallery_* fields. Tasks retry up to 6× with 1-hour delays — see services-and-tasks.md. All four webhook payloads include event_ts (ISO 8601 datetime captured at signal time, not send time) so the Gallery can drop stale retried events. 4xx responses are permanent failures for all four webhooks (no retry); 5xx retries via Huey.
    PayPal Membership payments PAYPAL_CLIENT_ID + PAYPAL_SECRET_KEY env vars; PayPalConfiguration model (singleton). PayPal does not support AED — charges USD, displays AED. The one-time lifetime membership uses the one-time PayPal order flow in api/views/views_payment.py (create_order/capture_order, PAYMENT.CAPTURE.COMPLETED webhook verified with PAYPAL_WEBHOOK_ID); on capture it grants lifetime membership (paid_member=True) via grant_membership (idempotent on the order id). No PayPal Subscriptions API / auto-renew — the rolling-subscription model was reverted (issue #169).
    Bugsink (Sentry-compatible) Error tracking SENTRY_DSN env var (intentionally keeps the Sentry variable name but points at the Bugsink project DSN). bugsink service in infra/docker-compose.yml. Sentry SDK is configured not to send request bodies or local frame variables; a before_send hook scrubs common secret-bearing keys, URL query parameters, and key=value breadcrumb strings before they leave the app.
    Gmail SMTP Transactional email EMAIL_HOST_USER + EMAIL_HOST_PASSWORD env vars

    Routine 500 emails vs Bugsink¶

    django.request logs always go to console. AdminEmailHandler 500 emails are enabled when SENTRY_DSN is blank. Once Bugsink is configured, they are disabled unless DJANGO_ENABLE_ADMIN_ERROR_EMAIL=true explicitly re-enables them. Operational emails (backup-failure alerts, disk-space alerts) are a separate channel and remain.
