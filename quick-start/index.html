    Quick Start Guide¶

    Get started with the AD4x4 API in 5 minutes.

    Prerequisites¶

    • API endpoint: http://localhost:8000/api/ (development)
    • Authentication: JWT Bearer token
    • Time zone: Asia/Dubai (UTC+4)

    Step 1: Authenticate¶

    Obtain Token¶

    curl -X POST http://localhost:8000/api/token/ \
  -H "Content-Type: application/json" \
  -d '{
    "username": "your_username",
    "password": "your_password"
  }'

    Response:

    {
  "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

    Use Token in Requests¶

    Include the token in the Authorization header:

    curl -X GET http://localhost:8000/api/trips/ \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

    Step 2: Explore Available Data¶

    List Trips¶

    curl -X GET "http://localhost:8000/api/trips/?approval_status=APPROVED" \
  -H "Authorization: Bearer YOUR_TOKEN"

    Get Levels¶

    curl -X GET http://localhost:8000/api/levels/ \
  -H "Authorization: Bearer YOUR_TOKEN"

    Get Meeting Points¶

    curl -X GET http://localhost:8000/api/meetingpoints/ \
  -H "Authorization: Bearer YOUR_TOKEN"

    Step 3: Common Operations¶

    Create a Trip¶

    curl -X POST http://localhost:8000/api/trips/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "lead": 123,
    "level": 10,
    "meetingPoint": 1,
    "title": "Weekend Desert Safari",
    "description": "Easy desert drive",
    "startTime": "2024-12-15T07:00:00+04:00",
    "endTime": "2024-12-15T15:00:00+04:00",
    "cutOff": "2024-12-14T18:00:00+04:00",
    "capacity": 10,
    "allowWaitlist": true
  }'

    Register for a Trip¶

    curl -X POST http://localhost:8000/api/trips/456/register/ \
  -H "Authorization: Bearer YOUR_TOKEN"

    Search Members¶

    curl -X GET "http://localhost:8000/api/members/search/?query=john" \
  -H "Authorization: Bearer YOUR_TOKEN"

    Step 4: Check Your Profile¶

    curl -X GET http://localhost:8000/api/members/me/ \
  -H "Authorization: Bearer YOUR_TOKEN"

    Response Format¶

    Success Response¶

    {
  "success": true,
  "message": "operation_successful"
}

    Or for data responses:

    {
  "success": true,
  "message": { ...data object... }
}

    Error Response¶

    {
  "success": false,
  "message": "error_description"
}

    Time Zone Note¶

    All dates use Asia/Dubai time zone (UTC+4) with no daylight saving time. Examples:

    • 2024-12-15T07:00:00+04:00 - December 15, 2024 at 7:00 AM Dubai time
    • 2024-12-14T18:00:00+04:00 - December 14, 2024 at 6:00 PM Dubai time

    Field Naming¶

    • Request body: Use camelCase (startTime, endTime)
    • Response body: Returns camelCase (startTime, endTime)
    • Database/Serializer: Uses snake_case internally

    Troubleshooting¶

    Issue Solution
    401 Unauthorized Check token is valid and not expired
    403 Forbidden Verify you have required permissions
    400 Bad Request Check request body format and required fields
    Rate limited (429) Wait 60 seconds before retrying
