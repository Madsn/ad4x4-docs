    Trip Requests¶

    This document outlines the trip request (proposal) system where members can suggest trip ideas that are then voted on by the community.

    Overview¶

    Trip requests allow members to propose trip ideas. Other members can vote on these proposals, and the results are aggregated to help trip organizers understand community interest.

    Endpoints¶

    List Trip Requests¶

    • GET /api/triprequests/
    • GET /api/triprequests/{id}/
    • Requires VIEW_UPGRADE_REQ permission or viewing own requests

    Response:

    {
  "count": 10,
  "results": [
    {
      "id": 1,
      "member": {
        "id": 123,
        "username": "johndoe",
        "firstName": "John",
        "lastName": "Doe"
      },
      "timeOfDay": "MORNING",
      "area": "DUBAI",
      "level": {
        "id": 10,
        "name": "Newbie",
        "numericLevel": 10
      },
      "date": "2024-12-20",
      "voteCount": 5,
      "created": "2024-11-15T10:00:00+04:00"
    }
  ]
}

    Create a Trip Request¶

    • POST /api/triprequests/

    Request Body:

    {
  "timeOfDay": "MORNING",
  "area": "DUBAI",
  "level": 10,
  "date": "2024-12-20"
}

    Response:

    {
  "success": true,
  "message": {
    "id": 1,
    "member": 123,
    "timeOfDay": "MORNING",
    "area": "DUBAI",
    "level": 10,
    "date": "2024-12-20",
    "voteCount": 0,
    "created": "2024-11-15T10:00:00+04:00"
  }
}

    Vote on a Trip Request¶

    • POST /api/triprequests/{id}/vote/
    • Requires VOTE_UPGRADE_REQ permission

    Request Body:

    {
  "vote": "yes"
}

    Response:

    {
  "success": true,
  "message": "vote_registered"
}

    Aggregate Trip Requests¶

    • GET /api/triprequests/aggregate/
    • Returns aggregated vote counts grouped by time of day, area, level, and date

    Query Parameters: - includeLevel: Include level in grouping - includeArea: Include area in grouping - includeTimeOfDay: Include time of day in grouping - includeDate: Include date in grouping

    Response:

    [
  {
    "timeOfDay": "MORNING",
    "area": "DUBAI",
    "level": "Newbie",
    "date": "2024-12-20",
    "voteCount": 15
  }
]

    Export Trip Requests Matrix¶

    • GET /api/triprequests/export/
    • Returns trip request data in CSV format
    • Requires authentication

    Response:

    Content-Type: text/csv
Content-Disposition: attachment; filename="trip_requests_2024-11-15.csv"

member,time_of_day,area,level,date,vote_count
123,MORNING,DUBAI,10,2024-12-20,5

    Query Parameters for List¶

    Parameter Type Description
    time_of_day string Filter by time of day (MORNING, AFTERNOON, EVENING)
    area string Filter by area (DUBAI, ABU_DHABI, etc.)
    level integer Filter by level ID
    date date Filter by specific date
    member integer Filter by member ID
    page integer Page number
    page_size integer Results per page (default: 20)

    Enums¶

    TimeOfDayChoice¶

    Value Description
    MORNING Morning trips
    AFTERNOON Afternoon trips
    EVENING Evening trips

    AreaChoice¶

    Value Description
    DUBAI Dubai area
    ABU_DHABI Abu Dhabi area
    AL_AIN Al Ain area
    NORTHERN Northern regions
    LIWA Liwa area

    Permissions¶

    Action Permission Required
    List trip requests VIEW_UPGRADE_REQ or own requests
    Create trip request Any authenticated user
    Vote on request VOTE_UPGRADE_REQ
    Export requests VIEW_UPGRADE_REQ
    Aggregate requests Any authenticated user

    Use Cases¶

    1. Proposing a trip idea: Create a trip request with desired time, area, level, and date
    2. Gauging interest: Other members vote on the proposal
    3. Organizing trips: Trip leads can use aggregate data to see what trips members want
    4. Planning: Results help organizers plan future trips based on community interest
