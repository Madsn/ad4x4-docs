    Vehicles¶

    This document outlines the API endpoints for managing member vehicles. Members can now register multiple vehicles, with a configurable limit set in global settings.

    Vehicle List¶

    Retrieve all vehicles for the authenticated user.

    GET /api/vehicles/

    Authentication: Required (Bearer token)

    Query Parameters: - page - Page number (default: 1) - page_size - Number of results per page (default: 20, max: 500)

    Success Response:

    {
  "count": 2,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 1,
      "name": "My Land Cruiser",
      "brand": "TOYOTA",
      "brandDisplay": "Toyota",
      "model": "Land Cruiser",
      "year": 2020,
      "color": "White",
      "isPrimary": true
    },
    {
      "id": 2,
      "name": "Nissan Patrol",
      "brand": "NISSAN",
      "brandDisplay": "Nissan",
      "model": "Patrol",
      "year": 2019,
      "color": "Black",
      "isPrimary": false
    }
  ]
}

    Create Vehicle¶

    Create a new vehicle for the authenticated user.

    POST /api/vehicles/

    Authentication: Required (Bearer token)

    Request Body:

    {
  "name": "My Land Cruiser",
  "brand": "TOYOTA",
  "model": "Land Cruiser",
  "year": 2020,
  "color": "White",
  "isPrimary": true
}

    Fields: | Field | Type | Required | Description | |-------|------|----------|-------------| | name | string | No | User-friendly name for the vehicle | | brand | string | Yes | Car brand code (e.g., "TOYOTA", "NISSAN") | | model | string | No | Vehicle model | | year | integer | No | Year of manufacture | | color | string | No | Vehicle color | | image | file | No | Vehicle image (multipart/form-data) | | isPrimary | boolean | No | Set as primary vehicle (default: false) |

    Validation: - Maximum number of vehicles is limited by vehicle_limit_per_member setting (default: 3) - brand must be a valid CarBrand choice

    Success Response:

    {
  "success": true,
  "message": {
    "id": 1,
    "member": 123,
    "name": "My Land Cruiser",
    "brand": "TOYOTA",
    "brandDisplay": "Toyota",
    "model": "Land Cruiser",
    "year": 2020,
    "color": "White",
    "image": null,
    "isPrimary": true,
    "createdAt": "2026-03-05T00:00:00.000Z",
    "updatedAt": "2026-03-05T00:00:00.000Z"
  }
}

    Error Response (limit reached):

    {
  "success": false,
  "message": "Maximum number of vehicles (3) reached. Please delete an existing vehicle first."
}

    Get Vehicle¶

    Get details of a specific vehicle.

    GET /api/vehicles/{id}/

    Authentication: Required (Bearer token)

    Success Response:

    {
  "success": true,
  "message": {
    "id": 1,
    "member": 123,
    "name": "My Land Cruiser",
    "brand": "TOYOTA",
    "brandDisplay": "Toyota",
    "model": "Land Cruiser",
    "year": 2020,
    "color": "White",
    "image": "/media/vehicles/2026/03/vehicle_abc123.jpg",
    "isPrimary": true,
    "createdAt": "2026-03-05T00:00:00.000Z",
    "updatedAt": "2026-03-05T00:00:00.000Z"
  }
}

    Update Vehicle¶

    Update a vehicle's details.

    PATCH /api/vehicles/{id}/

    Authentication: Required (Bearer token)

    Request Body:

    {
  "year": 2021,
  "color": "Silver"
}

    Note: Users can only update their own vehicles.

    Delete Vehicle¶

    Delete a vehicle.

    DELETE /api/vehicles/{id}/

    Authentication: Required (Bearer token)

    Note: If the deleted vehicle was the primary vehicle, the most recently created remaining vehicle will be automatically set as primary.

    Set Primary Vehicle¶

    Set a vehicle as the primary vehicle. Only one vehicle can be primary at a time.

    POST /api/vehicles/{id}/set_primary/

    Authentication: Required (Bearer token)

    Success Response:

    {
  "success": true,
  "message": {
    "id": 2,
    "member": 123,
    "name": "Nissan Patrol",
    "brand": "NISSAN",
    "brandDisplay": "Nissan",
    "model": "Patrol",
    "year": 2019,
    "color": "Black",
    "isPrimary": true,
    ...
  }
}

    Car Brand Choices¶

    Get available car brand choices.

    GET /api/choices/carbrands/

    See Choices API for details.

    Global Settings¶

    The vehicle limit per member can be configured in global settings:

    • vehicle_limit_per_member - Maximum number of vehicles a member can register (default: 3)

    Trip Registration with Vehicle¶

    When registering for a trip, members must select which vehicle they will use. The vehicle information is stored with the trip registration and displayed in the trip details and export.

    Register for Trip¶

    POST /api/trips/{tripId}/register

    Authentication: Required (Bearer token)

    Request Body:

    {
  "vehicleId": 123
}

    Fields: | Field | Type | Required | Description | |-------|------|----------|-------------| | vehicleId | integer | Yes | ID of the vehicle to register with |

    Validation: - User must have at least one vehicle registered - Vehicle must belong to the user - Vehicle is required (returns 400 error if not provided)

    Success Response:

    {
  "success": true,
  "message": "trip_registered"
}

    Error Responses:

    No vehicles registered:

    {
  "success": false,
  "message": "vehicle_required"
}

    Vehicle not found or doesn't belong to user:

    {
  "success": false,
  "message": "vehicle_not_found"
}

    Trip Registration Response¶

    When retrieving trip details, each registration includes the selected vehicle:

    {
  "registered": [
    {
      "id": 1,
      "member": {
        "id": 123,
        "username": "johndoe",
        "firstName": "John",
        "lastName": "Doe"
      },
      "vehicle": {
        "id": 456,
        "name": "My Land Cruiser",
        "brand": "TOYOTA",
        "brandDisplay": "Toyota",
        "model": "Land Cruiser",
        "year": 2020,
        "color": "White",
        "isPrimary": true
      },
      "checkedIn": false,
      "registrationDate": "2026-03-05T10:00:00.000Z"
    }
  ]
}

    Trip Export¶

    When exporting trip registrants, the CSV includes the selected vehicle:

    • Column: car_brand_model_color - Contains the vehicle brand, model, and color from the selected vehicle

    See Global Settings for more details.
